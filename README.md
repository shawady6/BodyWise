# BodyWise

**خطوة صغيرة كل يوم.**

تطبيق Android شخصي (Kotlin + Jetpack Compose)، واجهة عربية RTL، يعمل بدون إنترنت وبدون حسابات.

## الأقسام
1. **الأكل والشرب:** أسبوع من السبت للجمعة مع التنقل بين الأسابيع، فطار/غداء/عشاء (إضافة، تعديل، حذف، اقتراح أكلات سابقة، نسخ وجبات اليوم السابق)، مياه لأي يوم بهدف قابل للتعديل، وملخص أسبوعي.
2. **الوزن والمقاسات:** رسم بياني لكل مقياس، تسجيل وتعديل وحذف القياسات بتاريخ يدوي، وصور تقدم (كاميرا/معرض) بتدوير تلقائي وحجم محسّن، مع مقارنة قبل/بعد.
3. **الإعدادات:** مظهر (تلقائي/فاتح/داكن)، تذكيرات (مياه + قياسات الأسبوع)، قفل بالبصمة، نسخ احتياطي كامل بالصور واستعادة آمنة، نسخ أسبوعي تلقائي لمجلد تختاره، وتحديث التطبيق من GitHub.

## هيكل المشروع
```
app/src/main/java/com/shawady/bodywise/
├── MainActivity.kt
├── data/      نماذج البيانات، التخزين المحلي، تحويل JSON (متوافق مع الإصدارات القديمة)
├── util/      التواريخ والأرقام والصور
├── backup/    النسخ الاحتياطي ZIP والاستعادة والنسخ التلقائي الأسبوعي
├── update/    فحص الإصدارات، التنزيل مع SHA-256، التثبيت عبر PackageInstaller
├── security/  قفل البصمة
├── notify/    التذكيرات (WorkManager)
└── ui/        BodyWiseViewModel + الشاشات (food / progress / settings) + المكونات والثيم
```

## البناء
JDK 17 و Gradle 8.11.1:
```bash
gradle testDebugUnitTest assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`

## الإصدارات والتحديث
راجع [docs/RELEASING.md](docs/RELEASING.md). التحديث من داخل التطبيق ينزّل APK من آخر Release، يتحقق من SHA-256 وتوقيع الشهادة، ثم يفتح مثبت Android لموافقتك. لا يتم تثبيت أي شيء بصمت.

## الخصوصية
لا AI ولا حسابات ولا تحليلات ولا مزامنة سحابية. البيانات والصور على الجهاز فقط. الإنترنت لفحص وتنزيل تحديثات GitHub فقط. النسخ التلقائي يكتب في مجلد تختاره أنت على جهازك.
