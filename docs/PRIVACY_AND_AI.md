# Privacy, AI and Safety

- Do not commit personal health data, progress photos, backups or API keys.
- Keep profile, logs and photos in app-private local storage by default.
- Cloud AI and cloud backup must be explicit opt-in features.
- Never embed provider secrets in the Android APK. Use a secure backend for cloud credentials.
- AI food analysis returns an estimate/draft, not a verified fact. User reviews and confirms it.
- Explain uncertainty in portion size, ingredients and nutrition values.
- Calculators such as BMI, BMR and TDEE are estimates, not medical measurements.
- Do not diagnose conditions, prescribe treatment, encourage starvation or shame the user.
- Provide a clear data export and delete-all-data path before public release.
